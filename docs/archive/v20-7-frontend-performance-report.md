## 3. Bundle-impact opportunities

The V20.7 lazy-route helper enables the following bundle wins. They
are **opt-in per route** to keep V20.7 risk surface minimal — apply
during the next migration of each page.

| Route | Today (eager) | After `lazyRoute` | Notes |
| --- | --- | --- | --- |
| `/subscribers` | ~ 89 KB inlined into main chunk | Dedicated `subscribers.[hash].js` | Largest single page |
| `/payroll-unified` | ~ 72 KB inlined | Dedicated `payroll.[hash].js` | Heavy with Excel exports |
| `/monthly-report-full-print` | ~ 50 KB inlined + pdf-lib | Dedicated chunk + dynamic `import('pdf-lib')` | Print-only |
| `/system-settings` | ~ 47 KB inlined | Dedicated chunk | Admin-only |
| `/unpaid-invoices` | ~ 46 KB inlined | Dedicated chunk | Replaceable by `OutstandingTable` |
| `/staff-debts` | ~ 43 KB inlined | Dedicated chunk | Heavy filter forms |
| `/financials` | ~ 40 KB inlined | Dedicated chunk | Multi-tab |

The pattern (after migration):

```ts
import { lazyRoute } from '@/modules/shared/routing/lazy-route';

const SubscribersPage = lazyRoute(() =>
  import('@/pages/subscribers-page').then((m) => ({
    default: m.SubscribersPage,
  })),
);
```

Estimated combined initial-bundle reduction once all 7 above are
lazy-loaded: **~ 380 KB pre-gzip** (≈ 30 % of `pages/` shipped JS).

## 5. Selector / re-render hygiene

- All Phase 3 design-system components are pure props consumers — no
  internal subscriptions to global stores.
- `KPIWidget`, `FinancialStatCard`, `BranchBadge` re-render only when
  their props change (no inner state).
- `OutstandingTable` and `FinancialTimeline` defer row creation to
  `WindowedList` so React commits cost O(visible).
- The `useCollectorShortcuts` keyboard hook attaches a single
  `keydown` listener at `window` (one listener for the whole
  workspace, not one per shortcut).

## 8. Risks / TODO carried out of Phase 6

1. **Eager route loading remains in `App.tsx`** — the helper is in
   place but the 94-import central router has not been migrated.
   Migration is route-by-route to avoid a single big-bang PR.
2. **Heavy-lib dynamic imports** still inline `exceljs` and `pdf-lib`
   in their consumer pages. Tagged for the next maintenance window.
3. **Tests use jsdom** — no real paint-time measurements. The render
   bound (visible-only) is the ground truth contract; absolute
   millisecond budgets need a Chromium-headless run.

## 9. Rollback

All Phase 6 additions are **additive**:

- Removing `lazyRoute` removes 1 file; nothing else depends on it.
- Removing `windowed-list.perf.test.tsx` removes 1 test file;
  `WindowedList` itself is unchanged.
- The new design-system primitives are barrel-exported but never
  imported by legacy code yet — deletion is safe.
