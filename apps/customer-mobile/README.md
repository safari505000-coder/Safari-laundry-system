# Safari ERP Customer Mobile

This folder is reserved for the customer mobile app.

## Recommended path

Build as a real Expo / React Native app after the public web and customer portal API are stable.

Why:

- One codebase for Android and iOS.
- Native push notifications through Expo Notifications.
- Can reuse `packages/shared-api` contracts.
- Keeps the mobile app separate from the internal admin `web` app.

## Customer features

- Login with phone + OTP.
- Create pickup/order request.
- Track order status.
- View invoices and outstanding debt.
- Pay through backend-generated payment links.
- View subscription balance and expiry.
- Receive push notifications for order status and payment reminders.

## Auth and payment decisions

- WhatsApp OTP infrastructure is planned but not active yet.
- Temporary development mode can use phone-based lookup only.
- Gateway target is UPayments.
- Payment links must be generated by backend API only.

## Safety rules

- Do not calculate money in the app.
- Do not close invoices from the app.
- Do not write directly to ledger or journal endpoints.
- Always call the backend public/customer API.
- Display only canonical KWD strings returned by the API.
