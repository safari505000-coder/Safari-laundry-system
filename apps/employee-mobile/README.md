# Safari ERP Employee Mobile

This folder is reserved for the employee mobile app for drivers, call center, and managers.

## Recommended path

Use Expo / React Native after the employee API feed is stable.

The employee app should stay separate from:

- `web`: internal desktop/admin interface.
- `apps/public-web`: public company website and customer portal.
- financial write logic in backend services.

## Roles

- Driver: tasks, pickup/delivery, collection status, barcode/QR scan, mandatory GPS.
- Call Center: customer lookup, order follow-up, payment link requests, debt follow-up.
- Manager: task monitoring, driver status, exception review.

## Device capabilities

- GPS: mandatory for driver field task actions.
- Camera scan: QR/barcode for invoice/order lookup.
- Push notifications: new task, changed task, collection required.
- Notifications provider: Expo Notifications.

## Safety rules

- The app must not calculate KWD totals.
- Cash/KNET collection must call protected backend endpoints.
- Payment links must be generated by the backend only.
- Driver only sees assigned tasks.
- Manager and call-center access must follow existing RBAC.
- Driver collection authority stays exactly the same as current ERP permissions.
- UPayments links must be created by protected backend endpoints only.
